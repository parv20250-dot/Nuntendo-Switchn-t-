# Nuntendo-Switchn-t-
Hello hello hello person who has stumbled onto my GitHub repository, I'm so glad that you're here, before I go into my project some background on the name because I find it funny - I was initially thinking of designing a gaming console that runs existing games (like a switch)when I realised that that's too complex for me as of now ,so we improvise adapt overcome around here presentingggg the <ins>Nuntendo Switchn't <ins>,it is a gaming console containing games coded by yours truly, meee. The name itself is a pun and an abbreviation for nun (nothing)like a Nintendo, not a switch. Throughout this repository you will see my attempt at running a console that runs basic games such as pong,tetris,snake and maybe(if time permits and my coding abilities prevail) a subway surfer inspired endless runner.

Watch as I try to build a functional handheld gaming console on a budget and hopefully end up with something that doesn't spontaneously disappoint me or go kaboom.
